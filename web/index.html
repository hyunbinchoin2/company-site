    이 단계에서 쓰는 솔루션

    NMPS/NFPS는 모든 단계에서 시스템 개발과 운영을 지원합니다.

    솔루션

    대출 관리의 핵심 시스템부터 문서 발송, 보안, 비대면 채널까지 금융기관에 필요한 도구를 갖추고 있습니다.

    통합여신관리시스템

    nTree.NEXT AI

    금융기관마다 필수로 쓰는 채권관리를 중심으로 다양한 금융상품을 관리하고, 대출 업무를 편리하게 만드는 시스템입니다.

    채권관리금융상품 관리여신 업무 전반
    종합우편 DX서비스

    QUPID

    고객에게 보내는 문서를 전자우편과 전자문서로 발송하고, 배달 이력을 전산으로 관리합니다.

    앱/웹 금융서비스

    APP/WEB 금융서비스

    사용자 중심의 모바일 환경에서 비대면 금융 서비스와 시스템 연계를 지원합니다.

    개발 운영지원 시스템

    NMPS/NFPS

    금융 시스템의 개발과 운영을 지원합니다.

    가상 FAX 서비스

    Secure FAX

    팩스 기기 없이 보안이 적용된 가상 팩스로 문서를 주고받습니다.

    이미지 보안 솔루션

    Secure Image System

    금융 업무에서 다루는 이미지를 안전하게 보호합니다.
